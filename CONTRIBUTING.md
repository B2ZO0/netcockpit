# Contributing to NetCockpit

Thanks for your interest! Issues, ideas and pull requests are all welcome.

## Run it locally in 1 minute

```bash
docker compose -f docker-compose.demo.yml up --build     # http://localhost:8088
# or, without Docker:
pip install pyyaml requests && python demo/demo.py
```

The demo (`demo/demo.py`) simulates the whole environment (scan, vCenter, SNMP, Zabbix, Prometheus, Alertmanager, Loki, AI). It is the fastest way to work on the UI or on the topology logic. Front-end files (`cockpit/static/`) are plain HTML/CSS/JS with no build step: edit and reload.

## Project layout

| Path | What |
|---|---|
| `cockpit/app/` | Cockpit back end (Python, standard library HTTP server): `scanner.py` (nmap, NetBIOS, traceroute), `vcenter.py`, `snmp.py`, `zabbix.py`, `sources.py` (Prometheus, Alertmanager, Loki), `model.py` (merge, tree, status, views), `ai.py`, `main.py` (loops, API, metrics) |
| `cockpit/static/` | Cockpit UI: `core.js` (shell, device sheet, search, AI), `topo.js` (tree layout + Cytoscape), `views.js` (other views) |
| `prometheus/`, `loki/`, `alertmanager/`, `blackbox/`, `syslog/` | Stack configuration and alert rules |
| `grafana/` | Provisioning; dashboards are generated by `scripts/gen_dashboards.py` |
| `agents/` | Alloy install scripts (Linux, Windows) |
| `demo/` | Simulated environment |
| `docs/` | Documentation |

## Guidelines

- Keep the "no access to network gear" use case first: every feature must degrade gracefully when a source is missing.
- No new runtime dependency without a good reason (the cockpit image is `python:3.12-slim` + nmap + net-snmp).
- Dashboards: edit `scripts/gen_dashboards.py`, not the generated JSON.
- Check before opening a PR: `python -m py_compile cockpit/app/*.py`, `node --check cockpit/static/*.js`, and run the demo. CI does the same, plus `promtool` and `amtool` checks.
- Never commit real IP addresses, host names or credentials (use RFC 1918 / RFC 5737 examples and `example.local`).

## Good first issues

- English translation of the UI (strings are in `cockpit/static/*.js`).
- Device fingerprints: more vendors and ports in `scanner.classify()`.
- Proxmox / Hyper-V inventory, as an alternative to vCenter.
